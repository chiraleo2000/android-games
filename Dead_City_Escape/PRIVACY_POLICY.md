Dead City Escape (`com.studio.deadcityescape`) is a violent offline game. It is not a children's app and it is not part of the Google Play Families program. Do not offer it to a child as a Families app.

## No account

The game has no account, no login, and no online profile. [LEGAL_NAME] does not ask for your name, email address, phone number, or advertising ID.

## Data that stays on this device

The game stores data only on this device:

- A save file with level, experience, settings, and run statistics
- A cache of generated art used to draw the city
- A local diagnostic log if the game hits an exception

That data is not sent off the device. There is no game server, no analytics upload, and no cloud save. Unity Analytics and Unity cloud diagnostics are disabled.

The in-app privacy policy button opens one address, defined only by `PlayReleaseInfo.PrivacyPolicyUrl`:

https://example.com/dead-city-escape/privacy

Host that page with this policy after [LEGAL_NAME] replaces the placeholders and a reviewer checks it against the PDPA.

## Delete

Settings includes **Delete all local data**. The game asks you to confirm. After you confirm, it erases the save, cache, and preferences on this device and starts fresh with no restored run. Uninstalling the app also removes this data.

## Children

This violent game is not directed at children. It should not be listed as a Families app.

## Permissions

The game does not request microphone access (`RECORD_AUDIO`) because it does not record audio. It does not request location. It does not force the Android internet permission for its own features.
