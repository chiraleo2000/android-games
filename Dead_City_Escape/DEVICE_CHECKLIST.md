# Device checklist

Run this on a phone after an ARM64 build from Unity 6000.3.11f1. This is a violent game with no account. It is not a Families app. Data stays on this device.

1. Install the app and open it offline. The main menu appears without a login.
2. Start a run, move, and leave the run so a save exists (finish, die, or return to the menu after progress is written).
3. Open **Settings** from the corner button.
4. Tap **Delete all local data**, then **Cancel**. Relaunch and confirm the previous progress is still there.
5. Open **Settings**, tap **Delete all local data**, then **Delete**. The game must say the data was deleted and start fresh with no restored run.
6. Force-close the app and relaunch. Level is 1, Continue is not offered, and the old best time is gone.
7. Open **Privacy policy** and confirm it uses https://example.com/dead-city-escape/privacy only.
8. If an error screen appears, tap **Continue** and confirm you can still play, or tap **Main menu** and start a new run.
