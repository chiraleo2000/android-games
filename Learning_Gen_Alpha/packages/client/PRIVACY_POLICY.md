## Data stays on the device

Solo puzzle progress, score, hints used, and error notes are stored only in local storage on the device. The store version does not require an account to play. It does not show ads. It does not send puzzle progress, scores, or diagnostic logs off the device. Logs kept on the device exclude personal content such as email addresses and local user paths.

The Android app declares `android.permission.INTERNET` so the WebView can load the packaged app and so the optional online lobby can reach a server you choose to run. Solo play does not use that permission to transmit progress. The app does not request `RECORD_AUDIO`, location, contacts, or any other runtime permission. Android backup is turned off, so a cleared profile is not restored by the system.

Online multiplayer, if you open it, is optional and is not required to play the solo puzzles. The first screen is the solo world, not a server connection screen.

## Clear data

Settings includes Clear All Data. After you confirm, solo progress is erased and is not restored.
