# Real-device checklist

Run this on a phone after a debug or release install. Do not treat a unit test as a substitute.

- The library opens with Thai and international instruments, each showing Thai and English names.
- Filters for striking, plucking, and pressing each show at least one instrument.
- Opening an instrument shows a generated 3D shape, not an empty screen.
- Orbit and zoom change the model.
- Tapping a note plays a synthesized tone. A second instrument sounds different.
- The cultural panel shows Thai and English text.
- Settings opens the privacy policy link from the in-app constant.
- Clear All Data asks for confirmation, then says the data was cleared.
- Force-close and reopen. Volume and the last instrument are back to the defaults.
