## Educational app for children

Inventors Workshop is an educational physics workshop for children and families. It teaches how gears, belts, springs, and switches move. It is meant to be used on a device you control.

## Data stays on the device

Machines, challenge progress, tutorial state, and error notes are stored only on the device, in local app storage. The app does not create accounts. It does not show ads. It does not send analytics or gameplay off the device. It does not sell personal information. Android backup is turned off, so clearing data is not restored from a device backup.

The Android package declares `android.permission.INTERNET` so the Capacitor WebView can load the bundled workshop from its local origin. The app does not open remote pages and does not upload workshop data.

The app does not ask for a child's name, email address, or precise location. Logs kept on the device exclude personal content such as email addresses and home-directory paths.

## Sharing a machine

Export creates a JSON file on the device so you can share a design yourself. Import reads a JSON file you choose. There is no online community and no upload to [LEGAL_NAME].

## Clear data

Settings includes Clear All Data. After you confirm, saved machines and challenge progress are erased. Progress is not restored.
